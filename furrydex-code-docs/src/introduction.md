# Introduction
A Furrydex can be easily programmed and modified with Lua scripts. You can create/edit Lua scripts over a USB connection, or through other Lua scripts. 

Don't own a furrydex? Currently, you can only make them. But in the future, they'll be for sale at [macroplastics.ca](https://www.macroplastics.ca)

### What's here, what's where?

This is the documentation for the software side of the furrydex; custom Lua functions and their corresponding C code.

To get started programming a Furrydex, continue to the next section: Uploading Lua

If you're looking for hardware information, check [meow.com](meow) for the hardware docs.
