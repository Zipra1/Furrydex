## Uploading Lua

The easiest way to program the Furrydex is by plugging it into a device that can edit text. A desktop is preferred, but a phone will work too.

Once plugged in, it will appear as a storage device containing all the files in the Furrydex. From here, you can freely edit the files in the Furrydex.

The Furrydex also (will) come preloaded with basic tools to manage files, but using an external device is more effective.
